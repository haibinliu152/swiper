轻量轮播图

·SimSwiper 是一个开箱即用且轻量的轮播图插件，同时也包含丰富的，可配置的选项，迷你的体积，压缩版仅仅14kb，基本满足大部分开发需求。

·支持响应式布局，当窗口和元素的尺寸发生变化时，SimSwiper会自动重置布局,防止布局错乱,影响观感。

·支持移动端、IE10+触摸。兼容性强、体积小巧、配置简单、响应迅速的特点。

普通配置 垂直方向 左右切换按钮 导航点 无限循环 禁用GPU加速 关闭触摸 自动播放 懒加载/惯性 过渡时间/动画 命名空间

# 默认配置

new SimSwiper(el);
参数
#el:字符串:传入的最外层容器的id/class(需要保证唯一)
默认开启触摸滑动,支持手机和PC端

# 图片懒加载

lazy: {
 enable: true,
 prop: "data-src"
 freeMode: true }
enable:boolean 开启开关 默认为false
prop:string 原始图片地址 为src以外的任何名字
freeMode:boolean, 开启后,滑动惯性将在切换过程中产生跨越偏移
适用场景:大图片加载,内容多的情况下,优化首次加载的性能

# 过渡时间/动画

{
 duration:number
 ease:string|'ease' 可参考css
}
当前 duration:1000
ease:'ease-in-out'
设置轮播的过渡动画和时间ms

wrapperClass: "swiper-wrapper" 包裹命名
注意：命名空间必须和DOM类名一一对应，否则会报错
